# Rede Social Fullstack

Projeto de rede social fullstack desenvolvido com foco em autenticação, gerenciamento de perfil e criação de posts.

## 🚀 Funcionalidades

* Cadastro de usuários
* Login com autenticação JWT
* Perfil de usuário
* Biografia personalizada
* Criação de posts
* Sistema de autenticação protegido
* API REST
* Integração entre frontend e backend

---

# 🛠 Tecnologias Utilizadas

## Frontend

* HTML5
* CSS3
* TypeScript

## Backend

* Node.js
* Express
* Prisma ORM
* JWT (JSON Web Token)

## Banco de Dados

* MongoDB

---

# 🔐 Autenticação

O sistema utiliza autenticação baseada em JWT (JSON Web Token), permitindo:

* Login seguro
* Rotas protegidas
* Identificação do usuário autenticado
