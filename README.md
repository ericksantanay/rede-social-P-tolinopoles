# Rede Social Fullstack

Projeto de rede social fullstack desenvolvido com foco em autenticação, gerenciamento de perfil e criação de posts.

## 🚀 Funcionalidades

* Cadastro de usuários
* Login com autenticação JWT
* Perfil de usuário
* Biografia personalizada
* Criação de posts
* Sistema de autenticação protegido
* API REST
* Integração entre frontend e backend

---

# 🛠 Tecnologias Utilizadas

## Frontend

* HTML5
* CSS3
* TypeScript

## Backend

* Node.js
* Express
* Prisma ORM
* JWT (JSON Web Token)

## Banco de Dados

* MongoDB

---

# 🔐 Autenticação

O sistema utiliza autenticação baseada em JWT (JSON Web Token), permitindo:

* Login seguro
* Rotas protegidas
* Identificação do usuário autenticado

# 🚀 Rodando o Frontend Localmente

Este guia mostra como rodar o frontend usando o Live Server.

---

# 📦 Pré-requisitos

* VS Code
* Extensão **Live Server**


---


# ▶️ Rodar o projeto

1. Vá até a pasta:

```bash
public/
```

2. Clique com botão direito em:

```bash
index.html
```

3. Clique em:

```bash
Open with Live Server
```

---

# 🌐 O navegador abrirá

```text
http://127.0.0.1:5500/public/index.html
```

---

# ⚠️ Importante

* O projeto já está com os arquivos JavaScript compilados
* Não é necessário rodar build
* Apenas abra o `index.html`

---

# ✅ Pronto

O frontend já estará funcionando localmente.
